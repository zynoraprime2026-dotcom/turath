About Turath

Turath (تراث, "heritage") is a database of Islamic manuscripts and historical events. It exists to preserve and share the intellectual heritage of the Ummah — the sciences, arts, history and scriptures that shaped civilisation for over fourteen centuries. Coverage is global, as Islam itself is global: from Andalus to Nusantara, Timbuktu to Samarkand, Istanbul to Delhi.

Built with a Vercel API and Postgres. Content is curated with respect; corrections are welcome via the admin panel.

Endpoints

MethodEndpointDescription
GET/api/manuscriptsList manuscripts. Query: q, language, subject, region, page. Returns { total, page, per, manuscripts[] }
GET/api/manuscripts/randomOne random manuscript
GET/api/manuscripts/dailyManuscript of the Day (same one all day)
GET/api/manuscripts/:idSingle manuscript by id
GET/api/eventsList historical events. Query: q, category, region, page
GET/api/events/:idSingle event by id
GET/api/statsArchive counts (manuscripts, events, subjects…)
POST/api/suggestionsSuggest a manuscript (public). Body: { title, author, language, subject, region, description, submitter }
GET/api/m/:idShareable HTML page — no key needed, no JSON
POST/api/manuscripts, /api/eventsAdd records — curators only (also needs x-admin-pass)
